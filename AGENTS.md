# Обязательные правила Codex

## Проверка через Graphify

1. Перед изменением существующего кода использовать Graphify для анализа связанных функций и файлов.
2. Проверять возможные последствия изменений через graphify_impact.
3. Находить связанные тесты через graphify_tests_for.
4. Если Graphify недоступен или индекс неполный, сообщить об этом. Не выдавать непроверенные зависимости за факты.
5. Не изменять утверждённую функциональность без разрешения владельца проекта.
6. После изменений запускать доступные сборки и тесты.
7. Сообщать результаты проверок, ошибки и ограничения.
8. Не объявлять работу завершённой без подтверждённых результатов проверок.

## Права на изменения

Владелец проекта утверждает функциональность.
Не выполнять дополнительные изменения без его разрешения.

## 10. Подготовка и предоставление установочных файлов

**Инструменты:** GitHub Actions, GitHub, Google Drive.

Для прошивки обязательно предоставить:

- USB_MERGED.bin — для установки по USB.
- OTA.bin — для обновления по Wi-Fi.
- Исходник .ino — по отдельному запросу.

Для Android-приложения:

- Подписанный APK для установки.
- Проверку совместимости с обновлением предыдущей версии.

Для локального приложения:

- Готовую сборку в соответствии с утверждённой архитектурой.
- Если приложение встроено в прошивку, отдельный установщик не требуется.

Для каждого предоставляемого файла обязательно указать:

- Название и версию.
- Размер файла.
- Контрольную сумму SHA-256.
- Коммит исходного кода.
- Способ установки.
- Реальную ссылку на файл.

Проверить содержимое предоставляемых архивов и соответствие файлов назначению.

Запрещено предоставлять несуществующие файлы, неподтверждённые ссылки или выдавать старые сборки за новые.

**Результат этапа:** проверенный комплект файлов, доступных для установки.
