## Ограничения и обнаруженные функциональные пробелы

**GitHub Pages — в основном статическое отображение.** В программе, опубликованной на HTTPS GitHub Pages, нет получения текущего `/api/status` с локального HTTP ESP32-S3. На экранах остаётся `Н/Д` вместо живых температур. Графики и журнал событий сайта также не являются текущими данными контроллера.

Причина архитектурная: HTTPS-страница GitHub Pages не может просто так отправлять обычные запросы на локальный HTTP `192.168.4.1` из Safari. Текущая реализация направляет пользователя в локальную панель по Wi-Fi вместо выдачи ложных показаний.

Текущая иллюстрация установки — векторная, не полная пиксельная копия утверждённого изображения. Переключатели и макет проверены программно, **физические iPhone 12/15 Pro/16 и их Safari не тестировались**. Контент GitHub Pages нельзя было получить напрямую из доступной среды (открытие публичного URL не удалось); поэтому успешный deployment Actions не приравнивается к визуальной проверке сайта в Safari.
