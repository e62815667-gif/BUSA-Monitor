# БУСА-1М №001 — единый веб-дизайн, онлайн и локальная панель

Онлайн-экран базируется на официальном BUSA-Monitor V14.5 и на утверждённых шести макетах TFT / `BUSA_ApprovedGraphics_HQ_V14.h`. Сохранены цветные карточки, шесть диагностических разделов и условная иллюстрация оборудования. Добавлена седьмая вкладка **Калькулятор** как заглушка без вычислений. Во всех вкладках используются общие цвета (тёмно-синий/голубой, зелёная активная вкладка) и единая навигация.

* Онлайн: `online/index.html` — только read-only по Google Apps Script (`BUSA_VIEW_TOKEN`). Не использовать записывающий `BUSA_TOKEN`.
* Локальный интерфейс: встроенный HTML в `firmware/BUSA_1M_WIFI_3v_GOOGLE/BUSA_Main.h` — те же правила оформления, добавленная вкладка Калькулятор не отправляет команд на аппаратные выходы.
* Физический TFT 320×240 сохраняет шесть утверждённых основных вкладок, визуальная палитра выравнивается отдельно без изменения распиновки, кнопок и назначения физических модулей.
* Контроль передачи: три индикатора ИНТ/ЛОК/ДАН в онлайн-версии; зелёный ДАН означает включённую конфигурацию отправки, НЕ подтверждённую доставку. Отсутствие свежих данных показывает неизвестное состояние, а не выдуманный сигнал.
* Графики показывают только фактические измерения. При отсутствии DS18B20 графики пустые.
* Секреты только в настройках конкретного iPhone, не в репозитории. Не передавать публично ни `BUSA_VIEW_TOKEN`, ни `BUSA_TOKEN`.

Физически установленная V14.9 этим проектным изменением НЕ затрагивается. Доработки прошивки существуют только в отдельной ветке; сборка и аппаратная проверка обязательны до любых обновлений устройства.
