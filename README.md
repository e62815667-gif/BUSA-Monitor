## Как определять готовую прошивку

**Последняя успешная сборка CI и последняя проверенная на оборудовании прошивка — разные понятия.** Проверка сборки в Actions не подтверждает работу на физическом устройстве. Ветка `main` также не обязательно содержит самую новую сборку.

Для выпуска готового комплекта требуются **два файла**: USB merged BIN и OTA BIN. Проверяйте фактический состав релиза: опубликованный релиз от 03.11.2026 содержит OTA-файл и ZIP, но без USB merged BIN.

Исторические и экспериментальные ветки сохранены. Организация документации не изменяет код прошивки.
