## Эталон UI16

**BUSA UI16 успешно установлена и работает на ESP32-S3 N16R8 по подтверждению владельца от 15.11.2026.** Оба BIN-файла (USB MERGED, APP OTA) находятся в Google Диске «успех буса». Контрольные суммы проверены.

Точная исходная ветка UI16 ещё не установлена. В GitHub сохранена более ранняя CALC4/WIFI1, но её нельзя автоматически считать исходниками UI16. Успешная сборка CI и работа прошивки на реальном устройстве — разные уровни проверки.
