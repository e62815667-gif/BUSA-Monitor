# BUSA UI16 — голографический интерфейс

15.11.2026. База UI15 (`5aa4939`). Версия
`14v9-N16R8-RM-CALC4-WIFI1-UI16-20261115`.
ESP32-S3 N16R8, Arduino ESP32 2.0.17, Flash 16 MB, OPI PSRAM,
QIO, `app3M_fat9M_16MB`.

Выбранный третий вариант главной перенесён в работающий интерфейс:
графитовый фон, прозрачная голубая колонна, стеклянные панели и нижняя
навигация. Температуры остаются отдельными живыми подписями. На главной
нет порогов ВКЛ/ОТКЛ, указателей температуры или сканирующей прямоугольной
плоскости. Пороги доступны в разделе «Температуры».

Расход, израсходованная вода и отбор расположены одной строкой под
аппаратом, ниже — четыре существующих индикатора каналов. «Собрано»
выделено жёлтым, объём показан внутри приёмной ёмкости. В коротком
горизонтальном окне подписи куба и объёма вынесены рядом для читаемости.

Все шесть разделов получили общий стиль. На экране настроек вместе
остаются девять пунктов. Нет автоматического перелистывания и внешней
прокрутки. Длинные формы и результаты прокручиваются внутри своей панели.
Калькулятор сохраняет три режима, арифметику, точность, поля и сохранение
значений. Wi-Fi сохраняет выбор найденной сети, без ручного SSID.

Ресурсы встроены в прошивку, интернет для интерфейса не требуется.
Изображение аппарата не содержит надписей или примерных показаний.
Дополнительная анимация воды и отбора получает состояние из существующего
обновления реальных данных и останавливается при потере связи. Изображение
не пересоздаётся при опросе. Поддерживается системное уменьшение анимации.

Оформление: `web/holographic.css`, `web/design.js`; геометрия:
`web/viewport.*`. Встраивание: `ci/generate_design.py` и
`ci/generate_viewport.py`. Правки аппаратной части, GPIO, датчиков,
физического TFT, клавиатуры, Google, RainMaker и OTA в выпуск не входят.

## Установка

- `BUSA_UI16_APP_OTA.bin` — Настройки → Обновление ПО через Wi-Fi.
- `BUSA_UI16_USB_MERGED.bin` — прошивка через USB с адреса `0x0`.

OTA предпочтительно для сохранения текущих настроек. USB-образ может
перезаписать обычную NVS. Полное стирание не требуется. RainMaker `fctry`
не включается в компактный USB-образ.

Пакетирование: `ci/package_ui16.py`. Проверки описаны в
`docs/AUDIT_UI16.md`. Браузерные проверки с HTTP fixtures не заменяют
проверку физического ESP32 и Safari на iPhone.
