# Проверка исправления пагинации UI14

Основание: фотография меню настроек UI13 с восемью видимыми пунктами
и нижним счётчиком `1/2`. Пункт «О системе» оставался на втором листе.

Причина — общий алгоритм в `web/viewport.js`, который измерял отдельные
строки, распределял их между страницами и скрывал остальные через CSS.
UI13 исключила из алгоритма только две формы, поэтому механизм оставался
в меню и других разделах.

UI14 удаляет алгоритм, элементы управления и CSS скрываемых фрагментов.
Вместо него применяются:

- расчёт общей высоты девяти строк меню, с сохранением всех элементов;
- компактная компоновка температур и двух панелей воды/отбора;
- ограниченная высотой окна панель с доступным полным содержимым
  для длинных форм, журнала и диагностических отчётов;
- прежнее вписывание домашней иллюстрации и уменьшение графика
  с сохранением исходного соотношения сторон.

Производственный основной скрипт JS не меняется относительно UI13.
Операции API, аппаратные обработчики и калькулятор сохраняются.
Проверка стилей разрешает уменьшать только минимальную высоту строк
меню, сохраняя проверки шапки, индикаторов, навигации и графиков.

Регрессионная проверка сначала воспроизводит дефект на UI13. Затем
проверяются восемь окон, все девять пунктов одновременно, доступность
каждого пункта и вкладок диагностики, все разделы, 100 событий и
копирование всех 100 строк отчёта. Отсутствие пагинации проверяется
по отсутствию её DOM-элементов, а не только сокрытию кнопок.

Локально прошли проверки UI13, прежних стилей шапки и навигации,
живого опроса, выбора Wi-Fi, калькулятора и двухсекундного графика.
Проверки сохранения аппаратных контрактов, BLE/OTA/RainMaker и
актуальности встроенных ресурсов также пройдены. Сборка Arduino 2.0.17
успешна; полный HTML из текущего исходника побайтно найден в APP-образе.

Автоматические снимки и данные являются проверкой в Chromium с HTTP fixtures.
Это не фотография физического ESP32 или проверка Safari на настоящем iPhone.
Ограничения и установка описаны в README_UI14.md.
