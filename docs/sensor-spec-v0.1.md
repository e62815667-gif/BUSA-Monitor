# БУСА-1М — утверждённая конфигурация измерительных каналов
Версия 0.2 · 2026-10-13

## Решение владельца
Утверждён состав: четыре канала температуры (T01–T04) и один канал уровня жидкости (L01). Всего 5 каналов. Датчик крепости исключён из проекта приложения. Конкретные модели датчиков, схемы монтажа и интерфейсы не утверждены: их согласуют с будущей прошивкой БУСА-1М.

| ID | Назначение | Единица | Статус |
|---|---|---|---|
| T01 | Вода | °C | Канал утверждён |
| T02 | Колонна | °C | Канал утверждён |
| T03 | Куб | °C | Канал утверждён |
| T04 | Верх колонны | °C | Канал утверждён |
| L01 | Уровень жидкости | После выбора датчика | Канал утверждён |

## Проверка до покупки датчиков
Питание, электрический интерфейс, габариты, монтаж, материалы, условия среды, точность, калибровка, обслуживание и совместимость с прошивкой. При отсутствии связи выводить «Нет данных». Аппаратные защиты не зависят от приложения и ИИ.

## Калькулятор
Разработка приостановлена по решению владельца, к ней вернутся позже.
