# Границы изменения UI15

Основание: пользователь утвердил шесть отдельных макетов и поручил
перенести единый дизайн во все разделы локального приложения.

Изменены локальные CSS, адаптация калькулятора к общей рамке окна,
разметка легенды и единичной подписи отбора, значок настроек и версия.
Новый скрипт оформления только читает существующие температуры и обновляет
подписи легенды. Он не обращается к API и не управляет устройством.

Основной браузерный скрипт, файлы калькулятора и изображение аппарата
сохраняют контрольные суммы UI14. Нативный код вне встроенного HTML
совпадает с UI14 после нормализации единственной строки версии.
Обработчики API, датчики, физический TFT, клавиатура, выводы, разметка,
NVS, Google, RainMaker и OTA не переназначены.

Макеты служат образцом оформления, а не источником демонстрационных
значений в работающей прошивке. Проверки выполняют настоящий HTML/JS
приложения с имитацией ответов HTTP. Восемь размеров окна включают
маленький телефон, обычный портрет и горизонтальное положение.

Проверки охватывают все девять настроек без перелистывания, доступность
форм и полных отчётов, сохранение калибровки, выбор сети без ручного SSID,
устойчивость рисунка при опросе, текущие значения легенды/потерю связи,
реальную арифметику трёх калькуляторов, отсутствие команд устройству
при смене страниц и сохранение шага графика 2 с.

Сборка выполняется для исходного ESP32-S3 N16R8. Драйвер заказанного
ST7796 в этот выпуск не добавляется. Проверка на физическом приборе
и настоящем iPhone в данной среде недоступна.

Локально пройдены 23 исходных проверки CI, включая аудит UI12 с ASan/UBSan,
BLE/OTA, RainMaker, аппаратные контракты, расчёты и навигацию. Для местного
прогона задано `ASAN_OPTIONS=detect_leaks=0`: LeakSanitizer не работает
в данной среде под ptrace; проверки адресов и неопределённого поведения
остались включены. Сборка успешна, а весь текущий HTML побайтно найден
в готовом APP-образе.
