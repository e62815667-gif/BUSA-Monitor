# V15.3 RECOVERY2 — обслуживание сети и обновление без стирания NVS

Цель: устранить обнаруженные программные задержки после BOOTFIX1. Фактическая причина всех симптомов на подключённой плате без журнала ESP32 не подтверждена.

- Локальная страница передаётся с Content-Encoding gzip: 85 257 байт → 25 438 байт. Сжатие без потерь, состав страницы проверяется тестом. HTML не менялся функционально.
- Пакетное чтение 11 каналов PCA9685 заменено чтением одного канала за проверку. Физические выходы PCA не меняются.
- Полный поиск адресов I2C ограничен одним адресом за 100 мс; ошибочная клавиатура проверяется раз в секунду вместо постоянного повторения сканирования.
- Убран добавленный в BOOTFIX1 watchdog главного цикла. Обычная обработка ошибок и штатный watchdog ядра остаются.
- Ассоциация STA получает полные 12 секунд. Позднее событие DISCONNECTED от предыдущей операции не обрывает новую попытку. Повторные попытки через 5, 10, 20, 30 секунд; повторный запуск отсутствующего AP через 5 секунд. Работающая точка не перезапускается.
- Стартовая заставка сокращена с 8 до 1,2 секунды. Назначения GPIO и алгоритм температур не изменены.

Рекомендуемый USB-файл KEEP_SETTINGS: загружается с адреса 0xE000 на ESP32-S3 N16R8 с уже установленной V15.3. Включает boot_app0 и новое приложение app0; заканчивается в app0, не перекрывает NVS 0x9000…0xDFFF. Не выполнять Erase Flash/Erase All. Сохранённые настройки Wi-Fi, Google, привязки датчиков и калибровки остаются. Ранее уже стёртые настройки восстановить из такого обновления невозможно — их нужно ввести заново.

Полный образ для адреса 0x0 для этого обновления не требуется. Применение Erase All перед записью сотрёт настройки независимо от содержимого нового файла.

Тесты проверяют реальный автомат Wi-Fi в моделируемых событиях, включая поздний disconnect, таймауты и переполнение millis; температурный движок, звуковую сигнализацию, gzip и JavaScript. Это не заменяет испытание на основной плате с подключёнными модулями. Скорость загрузки USB также зависит от загрузчика, выбранной скорости и USB-UART; код приложения не управляет записью своего BIN загрузчиком.
