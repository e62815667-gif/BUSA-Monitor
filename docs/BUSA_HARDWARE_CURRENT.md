## Подключение UART — статус подтверждения
- Основная GPIO9 TX — синий провод (подтверждено владельцем 25.11.2026).
- Основная GPIO8 RX — жёлтый провод (подтверждено владельцем 25.11.2026).
- Экран: программные назначения HW1 — GPIO43 TX, GPIO44 RX, UART1, 115200 бод. Физические контакты экрана отдельно не подтверждены; не менять проводку без проверки.
- GND общий. Контакты 3,3 В плат между собой не соединять; логические уровни 3,3 В.
- Не использовать прежнюю схему UART или профиль старого GMT028-05/ST7789 для GUITION.

## Периферия по исходникам HW1 и документу фактической конфигурации
- DS18B20: T1 GPIO16, T2 GPIO17, T3 GPIO18, T4 GPIO21.
- Два YF-S401: вода GPIO15, отбор GPIO1, независимая калибровка; наличие импульсов не равно наличию датчика.
- PCF8575 0x20, SDA40/SCL41, клавиатура 5×4.
- Звуковые каналы K1–K4: GPIO7/6/5/4; MH-FMD GPIO2, активный LOW по коду.
- PCA9685 не установлен по документу HW1. Физическая проверка периферии и полярности зумера обязательна.
- Старый SPI-рендерер остаётся в HW1 до согласованного переноса клавиатуры; не удалять самостоятельно.
- Изученная ревизия HW1: 64898ff4efc1c157000a16b0d4e57add71f0ffb3. Это промежуточная ревизия, не утверждённый полный выпуск.

## Сведения из предыдущего анализа (требуют повторной проверки)
RGB565, LVGL 8.3.7, Arduino_GFX, NV3041A (в прошлой документации есть расхождение драйверов), ESP-IDF 5.1.1, DIO 80 МГц; ориентировочное потребление 260 мА; размеры 120×70,2 мм, активная область 95,04×53,86 мм, рабочая температура −20…+70 °C. Не считать параметры независимо проверенными в текущем пакете. Заводской GUITION_FULL.bin: 4 194 304 байта, повторно сверить SHA-256 с оригиналом. Базовая версия экрана 1v, указанный ранее коммит ce7238436717406448c18d2a1fc82bf8500415fc: проверить доступность и принадлежность до использования. Поддержка OTA и совместная работа требуют фактических испытаний.
