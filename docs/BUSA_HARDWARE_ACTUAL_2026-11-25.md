# БУСА-1М №001 — фактическая конфигурация 25.11.2026

По перечню владельца и фотографиям: ESP32-S3 N16R8; четыре звуковых канала релейного модуля SONGLE SRD-12VDC-SL-C (катушки 12 В); PCF8575 0x20, клавиатура 5×4; четыре DS18B20; два независимых YF-S401 (вода GPIO15, отбор GPIO1); MH-FMD GPIO2, активный LOW; GUITION JC4827W543R_I 480×272. Другие периферийные модули не установлены. Сохранить настройки и алгоритмы. Пины UART сверять по фактической схеме и BUSA_DisplayProtocol.h; старый паспорт содержит расхождение.

HW1 — промежуточная ревизия. Устаревший SPI-рендерер ещё не исключён: его полное удаление зависит от переноса физической клавиатуры на GUITION. Не утверждать как полный выпуск. Полярность зумера по маркировке, практическая проверка обязательна. Приёмник Sheets изменён только в исходнике, развёртывание требует подтверждения. Старый столбец P сохраняется для истории, в новых записях пустой. Поле sensor_present сохраняет прежний смысл (наблюдение импульсов); installed — состав по владельцу, pulse_seen — факт импульсов. Калибровка не изменена.
