# Границы изменения UI16

Основание: пользователь выбрал третий голографический вариант главной,
попросил единый дизайн меню и остальных экранов, затем поручил сделать
прошивку. Графит выбран нейтральным фоном для общего набора экранов.

Изменения ограничены встроенным веб-интерфейсом и строкой версии.
Основной браузерный скрипт сохранён побайтно относительно UI15 (`5aa4939`).
Весь C++ вне HTML после нормализации строки версии совпадает с UI15.
Файлы калькулятора имеют прежние контрольные суммы. Обработчики API,
датчики, реле звуковых сигналов, GPIO, TFT, клавиатура, Wi-Fi, NVS,
Google, RainMaker, BLE и OTA не менялись.

Новый скрипт оформления перемещает существующие DOM-узлы показаний,
читает температуры, объёмы и состояния каналов. Он не обращается к API
и не отправляет команд устройству. Примерные числа из макетов в код
не включаются. Изображение аппарата заменено отдельным ресурсом WebP
без подписей; показания и анимация расположены независимыми слоями.

Проверки UI16 охватывают шесть разделов на восьми размерах окна,
расположение метрик и индикаторов, отсутствие обрезанных подписей,
скрытие порогов только на главной, отсутствие внешней прокрутки и пагинации,
неизменность DOM изображения при опросе, живые данные и потерю связи,
цвета датчиков и работу всех трёх калькуляторов. UI14 дополнительно
проверяет все девять настроек, поля, диагностику и полные отчёты.
UI13 сохраняет проверки калибровки и Wi-Fi без ручного SSID.

Историческая проверка UI15 отсутствия свечения заменена проверкой
утверждённого оформления UI16. В UI14 проверяется новая видимая строка
метрик вместо скрытой прежней подписи отбора. UI11 учитывает фактический
отступ новой рамки меню. Проверки сохранности контроллера и калькулятора
не ослаблены. Список допустимых версий BLE/OTA и аудита пополнен UI16.

Локальные проверки используют Chromium и HTTP fixtures. Физический ESP32,
Safari на iPhone и локальный WebKit в этой среде не проверялись. WebKit
предусмотрен в CI. Для нативных проверок локально отключается только LSan
(`ASAN_OPTIONS=detect_leaks=0`), недоступный под ptrace; ASan/UBSan остаются.

Локально пройдены 27 команд проверки исходников, генераторов и нативного
кода из CI, а также отдельная проверка полной сохранности backend UI16.
UI16 design, UI14 viewport, UI13 browser, UI11 style, UI9 live,
Wi-Fi browser и calculator browser пройдены в Chromium. Сборка успешна:
2 300 301 байт программы (73% раздела), 82 012 байт глобальных переменных.

Пакетирование проверяет ESP32-S3, версию, checksum/hash, разметку,
границы APP/USB, идентичность APP внутри USB и наличие полного текущего
HTML в готовом APP. Контрольные суммы выпуска фиксируются в `DELIVERY.md`.
