# БУСА-1М с ИИ №001 — структура интерфейса по утверждённому изображению

Актуализация: 21.10.2026. Основание: изображение пользователя с шестью макетами экранов.

**Главное правило:** шесть основных экранов без изменения названий и порядка:
1. **Главная**
2. **Температуры**
3. **Отбор**
4. **Графики**
5. **События**
6. **Настройки**

Навигационная панель с шестью иконками/подписями присутствует на каждом из шести экранов; выделяется текущий раздел. Верхняя панель: «БУСА-1М №001», Wi-Fi, **текущая дата и время**, индикатор состояния (если показатель действительно измеряется/определяется). Удобный интерфейс iPhone и TFT должен сохранять одинаковую структуру.

**Время и дата (дополнение пользователя):** отображать на каждом экране TFT и на iPhone. Формат TFT — `ДД.ММ ЧЧ:ММ`; формат iPhone — `ДД.ММ.ГГГГ ЧЧ:ММ:СС`, 24-часовой. Для синхронизации использовать время телефона при соединении с локальной сетью БУСА; при наличии интернета допускается NTP. Если достоверная синхронизация не выполнена, показывать прочерки/«Время не синхронизировано», не фиктивную дату. При изменении часового пояса учитывать установленный на телефоне часовой пояс.


## 1. Главная
- T1 Вода, T2 Колонна, T3 Куб, T4 Верх колонны: реальное измеренное значение, информационное поле «Зад.».
- Схематичное изображение установки (в проекте не подключает исполнительные узлы).
- Отбор: расход, собрано — только если установлен отдельный соответствующий измеритель; иначе «НЕТ ДАТЧИКА» / «НЕТ ДАННЫХ».
- Электропитание: напряжение только если есть измеритель; не подставлять демонстрационное значение 12.1 В.
- Wi-Fi и состояние мониторинга.

## 2. Температуры
- Четыре отдельные карточки: Вода, Колонна, Куб, Верх колонны.
- Для каждой карточки: фактическое значение DS18B20, «Зад.», «Авто» из исходного макета.
- «Зад.» и «Авто» в диагностической прошивке допускаются только как независимые информационные параметры; не являются выходами управления.
- Нажатие карточки открывает подробные настройки соответствующего датчика; числовая клавиатура появляется только при редактировании поля.

## 3. Отбор
- Текущий расход, Собрано жидкости, график расхода.
- Время отбора, средний/максимальный/минимальный расход.
- Кнопки: «Сброс», «История», «Назад» — только для информационной истории и счётчиков, без физического управления.
- Значения отбора не подменять импульсами датчика охлаждающей воды YF-S401. При отсутствии отдельного датчика показывать отсутствие данных.

## 4. Графики
- Внутренние вкладки: «Температуры», «Расход», «Питание».
- Временные периоды: «1ч», «6ч», «12ч», «24ч».
- Серии температуры: Вода, Колонна, Куб, Верх колонны.
- Периоды и кривые показывать по фактической истории; недостаточный интервал не восполнять фиктивными измерениями.

## 5. События
- Фильтры: «Все», «Предупр.», «Аварии», «Система».
- Журнал с временем, текстом и типом события; не выдумывать прошлые события и аварии.
- Приоритет — реальные диагностические события подключённых модулей и связи.

## 6. Настройки
Вложенные разделы точно по изображению:
1. «Температуры»
2. «Отбор жидкости»
3. «Wi-Fi»
4. «Экран и звук»
5. «Система»
6. «О системе»

Внутри «Системы» или связанных подменю могут находиться технические сервисные функции: диагностика модулей, Google-мониторинг и локальное обновление ПО; при реализации не заменять ими шесть верхнеуровневых строк данного макета.

## Известные ограничения и отличия реального стенда
- Изображение-референс выполнено для портретного TFT 240×320. **Реальный TFT утверждён в альбомной ориентации 320×240**, поэтому адаптировать композицию; не возвращаться к портретной только из-за картинки.
- Все числа на макете — примеры, а не подтверждённые показания физических датчиков.
- Блок управления 220 В и электропривод шарового крана ранее исключены из проекта. Не возвращать исполнительное управление этими устройствами.
- K1–K4 физически заблокированы в диагностической версии; ни один элемент UI не должен активировать исполнительные выходы.
- Для клавиатуры 5×4 требуется установить физическую матрицу и соответствие клавиш; **не считать ошибочное назначение V5 подтверждённой раскладкой**. #, *, ← и → — отдельные кнопки.
- Сохранить уже работающие Wi-Fi, web OTA, Google-мониторинг после настройки, TFT и реальные датчики.
