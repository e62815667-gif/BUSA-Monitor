# БУСА-1М с ИИ №001 — новая клавиатура 5×4 и PCF8575
Дата: 18.10.2026
Статус: распознавание модели/раскладки подтверждено по фото; физическая распиновка шлейфа НЕ подтверждена.

## Что видно на фотографиях
- Мембранная матричная клавиатура 5×4, 20 кнопок: верхний ряд F1, F2, #, *; затем 1,2,3, ↑; 4,5,6, ↓; 7,8,9, Esc; ←, 0, →, Ent.
- Синяя плата расширителя подписана PCF8575; маркировки портов P00…P07 и P10…P17 видны. Логический разъём на фото имеет метки INT, SCL, SDA, VCC, GND.
- Фото подтверждает внешний вид модулей, но не позволяет надёжно установить порядок девяти контактов шлейфа клавиатуры или точные соединения проводов с платой.

## Базовая логика прошивки v0.7.3-keypad-lab.1
- I²C-шина проекта: SDA GPIO8, SCL GPIO7, 100 kHz — использовать только после проверки фактической проводки.
- PCF8575 обычно адресуется 0x20…0x27; конкретный адрес должен быть найден сканированием I²C после проверки питания и шины.
- Лабораторный драйвер сканирует матрицу 5×4 через PCF8575 и записывает события в локальный API /api/keys. Дребезг подавляется, множественные одновременные нажатия блокируются.
- Входы клавиатуры не запускают физические нагрузки. Реле K1–K4, TFT и выходы PCA9685 остаются отключёнными.
- Команда USB Serial 115200 для обнаружения I²C после проверки проводки:
  {"cmd":"i2c","confirm":true}
- После того как обнаружены ожидаемые адреса, запуск мониторинга клавиатуры (адрес ниже — пример, не считать подтверждённым до сканирования):
  {"cmd":"keypad","address":32,"confirm":true}
- Отключить:
  {"cmd":"keypad_off"}
- Адрес 32 = 0x20; при сканировании может оказаться 0x21…0x27.

## Как безопасно установить порядок шлейфа
1. Отключить USB и 12 В, отсоединить мембранную клавиатуру от PCF8575.
2. Мультиметром в режиме прозвонки определить девять контактов: при нажатии каждой кнопки определить пары контактов, которые замыкаются. Не подавать напряжение на шлейф.
3. Записать таблицу «кнопка → пара контактов шлейфа» для всех 20 кнопок. Пары должны образовать матрицу с пятью линиями одной группы и четырьмя — другой.
4. Проверить маркировку питания PCF8575; не подавать 12 В на VCC. Не использовать INT как одну из девяти линий матрицы.
5. При отключённом питании проверить целостность проводов PCF8575 ↔ ESP32-S3. Проектная шина GPIO8/GPIO7 не является подтверждением того, как фактически подключён макет.
6. Только после проверки включить USB-логику, выполнить I²C scan, подтвердить адрес, затем включить командой keypad.
7. Проверить все кнопки по одной через /api/keys. Если порядок строк/столбцов отличается от принятой временной карты — не переподключать наугад; обновить карту по результатам прозвонки.

## Ограничения
Успешная компиляция не является проверкой на реальном железе. До прозвонки шлейфа нельзя утверждать, что конкретная физическая кнопка будет соответствовать отображаемой метке. Эта лабораторная версия не является готовой автоматикой; внешние нагрузки и K1–K4 не управляются.
