# BUSA UI8 — 07.11.2026

База UI7 1b0cdf0. Изменён только рисунок аппарата в локальном приложении на согласованный пользователем вариант с двумя холодильниками и широкими коленами. Источник: exec-fe8a3692-9816-414b-960b-111e1bddfa26.png; PNG перекодирован в WebP без изменения композиции. Позиции блика, подсветки двух холодильников и капель подогнаны под рисунок. Подсветка и капли по-прежнему зависят от данных датчиков; блик декоративный.

Физический интерфейс, аппаратные функции, пороги, настройки, API, единицы, графики и журнал сохранены. Условия и ограничения README_UI7.md остаются в силе. APP_OTA.bin для локальной сети, USB_MERGED.bin для USB с адреса 0x0; merged может перезаписать обычную NVS, полный erase не нужен.

Сборка и проверки на ПК; на ESP32 не устанавливалась.

Дополнение: по просьбе пользователя увеличено окно куба. Последний источник PNG exec-afc38bff-5ccf-4082-a237-f41fb4afe418.png. CSS-пузырьки и поверхность жидкости анимируются постоянно независимо от датчиков; это декоративное кипение, не показание состояния ТЭН/температуры. Reduced-motion сохраняется.
