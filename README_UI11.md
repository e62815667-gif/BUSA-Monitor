# BUSA UI11 — 07.11.2026

Исправление визуальной регрессии UI10. Возвращены размеры и оформление шапки, индикаторов подключения, нижней навигации, вкладок, заголовков, меню и остальных существующих элементов из UI9. Wi-Fi не переносится на две строки внутри индикатора. График сохраняет исходное соотношение 640:440, не растягивается на свободную высоту. Меню настроек заканчивается после последнего пункта, без принудительного пустого продолжения.

Главная по-прежнему помещается между шапкой и навигацией без прокрутки: одновременно видны реле, Колонна, Авария, Вода, Куб, пороги и нижние показания. Утверждённый рисунок и анимации сохранены. Для очень короткого окна график только уменьшается; на обычном портретном экране элементы сохраняют исходные размеры. Длинные формы и отчёты по-прежнему доступны через страницы. В диагностике исходные вкладки находятся на первой странице, следующие страницы показывают выбранную информацию; кнопка «Назад» возвращает к вкладкам. Отчёт копируется целиком.

Калькулятор и Wi-Fi исключены из новой компоновки. Исходный основной браузерный скрипт, разметка Wi-Fi и файлы калькулятора проверяются по контрольным суммам UI9. Их функциональные браузерные проверки проходят отдельно. Данные, API, периоды графиков 5/10/15/30 минут и 1 час, обновление 2 секунды не менялись. Нативные TFT, клавиатура, GPIO, NVS, BLE/OTA, RainMaker и обработка датчиков не менялись.

Проверки: Chromium, 320×568, 375×667, 390×744, 390×844, 430×932, 844×390; все главные показания и доступность страниц форм/отчётов; сравнение стилей с исходным оформлением; высота графика и меню; изменение размеров браузера и ввод; HTTP-опрос, калькулятор и Wi-Fi. WebKit здесь отсутствует. На реальный ESP32/iPhone сборка не устанавливалась.

Сборка: ESP32 Arduino 2.0.17, ESP32-S3 N16R8, OPI PSRAM, QIO, app3M_fat9M_16MB. Файлы:

- BUSA_N16R8_RM_CALC4_WIFI1_UI11_APP_OTA.bin — обновление через локальную сеть.
- BUSA_N16R8_RM_CALC4_WIFI1_UI11_USB_MERGED.bin — USB, адрес 0x0. Компактный merged не содержит раздел RainMaker fctry. Обычная NVS может перезаписываться при USB-загрузке; полный erase не требуется.

ci/package_ui11.py проверяет ESP32-S3, checksum/hash, размер приложения, разметку, адреса и совпадение приложения внутри USB-образа. web/viewport.css и web/viewport.js встраиваются через ci/generate_viewport.py. Тестовые измерения находятся только в HTTP fixtures, в прошивку не включаются.
