# Правила проекта BUSA-Monitor

## Назначение
Этот репозиторий предназначен для разработки приложения будущего БУСА-1М с ИИ и лаборатории.

## Области разработки
- БУСА-1М: мониторинг, автоматика, управление, аварийные состояния, ИИ.
- Лаборатория: измерения, эксперименты, сбор данных, графики, анализ.
- Приложение: интерфейсы телефона и компьютера, исходный код, тесты, документация.

## Хранение
- Основной архив исходников и документации — GitHub, репозиторий BUSA-Monitor.
- Каждое завершённое изменение сохраняется коммитом с понятным описанием.
- Версии приложения фиксируются в документации и истории Git.
- Локальные резервные копии на компьютере/диске создаются после настройки доступа к нему; GitHub сам по себе не является локальным диском.

## Безопасность
- Демонстрационные значения нельзя выдавать за реальные измерения.
- Управляющие команды не активировать до проверки аппаратной схемы и защит.
- Учётные данные, пароли, токены и ключи не сохранять в репозитории.

## Текущее состояние
- Первый мобильный демонстрационный интерфейс: index.html.
- Реальное подключение к оборудованию ещё не реализовано.
