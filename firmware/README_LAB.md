# BUSA-1M №001 — низковольтный лабораторный стенд

Мониторинг четырех DS18B20 по GPIO38, GPIO39, GPIO40, GPIO41. Проектные каналы K1–K4: GPIO7, GPIO6, GPIO5, GPIO4.

Без управления реле, силовыми цепями, краном и сетевыми устройствами. Неизвестные пороги не заменяются условными значениями. Аппаратное испытание не выполнено.
