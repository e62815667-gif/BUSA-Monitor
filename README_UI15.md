# BUSA UI15 — утверждённый дизайн шести разделов

14.11.2026. База: UI14 (`f471670`).
Версия `14v9-N16R8-RM-CALC4-WIFI1-UI15-20261114`.
Плата ESP32-S3 N16R8; Arduino ESP32 2.0.17, Flash 16 MB,
OPI PSRAM, QIO, `app3M_fat9M_16MB`.

Пользователь утвердил шесть макетов: главная, температуры, вода и отбор,
графики, калькулятор, настройки. UI15 переносит их общий стиль в настоящий
интерфейс: тёмно-синий фон, матовые панели, синие активные кнопки,
единые поля, размеры и отступы, простые иконки, отсутствие свечения.
Шапка и навигация оформлены одинаково во всех разделах. Выбранная ранее
светлая тема остаётся доступной; системная и тёмная используют новый стиль.

На главной сохранены исходный утверждённый аппарат и независимые слои
кипения, движения воды и отбора. Рисунок не заменён статическим макетом.
Подсветка блока реле показывает существующее реальное состояние каналов.
Вода — голубая, куб — жёлтый, колонна — зелёная, авария — красная.

Температуры расположены компактными строками без рамок. Вода и отбор —
две панели без графиков и повторяющейся подписи текущего отбора. Технические
статусы датчиков сохранены для средств доступности.

Графики сохраняют три вкладки, пять периодов и обновление 2 с. Новая
легенда получает текущие температуры из реальных обновлений, включая
очистку при потере связи. Числа и кривые из картинок в код не перенесены.

В калькуляторе обновлено только локальное оформление и прокрутка внутри
панели: шапка и нижняя навигация остаются на месте. Арифметика, три режима,
проверки, точность, сохранение и очистка введённых значений не менялись.
Все девять пунктов настроек доступны вместе, без «1/2» и перелистывания.

Оформление: `web/design.css`, `web/design.js`, генератор
`ci/generate_design.py`. Геометрия окна: `web/viewport.*`.
Все ресурсы встроены в прошивку и доступны без интернета.

## Проверки и установка

`tests/test_ui15_design.py` проверяет шесть разделов на восьми размерах
окна, единообразие шапки, цвета датчиков, отсутствие внешней прокрутки,
переходы, живую легенду и поведение калькуляторов. Сохраняются проверки
UI14, калибровки/Wi-Fi UI13, живых показаний, графиков и аппаратных контрактов.

Локальные браузерные проверки используют Chromium и HTTP fixtures.
Снимки с примерными значениями не являются проверкой физического ESP32
или Safari на iPhone. WebKit предусмотрен в CI.

- `BUSA_UI15_APP_OTA.bin`: локальное приложение → Настройки → Обновление ПО.
- `BUSA_UI15_USB_MERGED.bin`: запись через USB по адресу `0x0`.

Для сохранения текущих настроек предпочтительно OTA. USB-образ может
перезаписать обычную NVS. Полный erase не требуется; RainMaker `fctry`
не включается в компактный USB-образ. Пакетирование и проверка образов:
`ci/package_ui15.py`.
