# BUSA UI9 — 07.11.2026

База UI8 f0a1d59. В прошивку перенесён доработанный и выбранный пользователем второй макет. Изменения относятся к локальному приложению; физический интерфейс и управление оборудованием сохранены.

## Главная

Аппарат увеличен за счёт нижних отступов, царга и соответствующие металлические колена тоньше. Боковой холодильник короче и выше. Левый слив продолжается влево, нижний вход бокового холодильника вправо. Реле — компактным рядом над рисунком.

Названия без префикса «Т»: Колонна сверху слева, Авария сверху справа, Вода у левой трубки, Куб в широком окне. Пороги куба расположены под корпусом и выровнены по одной линии с отбором в мл/мин. Расход и израсходованный объём выровнены справа у трубки. Жёлтое «Собрано» и объём находятся внутри стакана.

Температуры, пороги, скорости и объёмы отображаются с одним знаком после запятой. Менее литра — мл, от литра — л. Время остаётся ЧЧ:ММ. Арифметика и точность расчётов калькулятора, протокол и сами измерения не изменены.

Источник изображения: exec-b4f0aca2-d446-424e-8013-e06fffd09337.png; PNG перекодирован в WebP без изменения композиции. Исходник картинки из выбранного макета встроен в HTML. Пузырьки в окне куба и движение поверхности в стакане постоянные и декоративные; не подтверждают физическое кипение или объём. Движение по водяным трубкам/спиралям включается при положительном расчётном расходе, по линии отбора — при положительных данных датчика отбора. Учитывается reduced-motion.

В релизе только реальные данные API: демонстрационные температуры, пороги, расходы и объёмы из эскизов отсутствуют. При потере связи показания очищаются, потоки останавливаются, состояния реле становятся неизвестными. Предыдущие реальные пороги остаются как настройки. В текущей аппаратной базе датчика отбора нет, поэтому его измерения остаются недоступными. Расходомер охлаждения не откалиброван: данные расчётные, как указано в разделе воды.

## Файлы

BUSA_N16R8_RM_CALC4_WIFI1_UI9_APP_OTA.bin — локальное обновление по Wi-Fi, предпочтительно для сохранения настроек.
BUSA_N16R8_RM_CALC4_WIFI1_UI9_USB_MERGED.bin — USB, адрес записи 0x0. Merged включает служебные области и может перезаписать обычную NVS; полный erase не нужен. Factory-раздел RainMaker не включён в компактный образ.

Официальный Arduino ESP32 2.0.17, ESP32-S3 N16R8, OPI PSRAM, QIO, app3M_fat9M_16MB. Пакетирование ci/package_ui9.py проверяет целевой чип, размер, checksum/validation hash, разметку и включение APP в USB. Условия README_UI7.md сохраняются.

## Проверки

Реальная сборка ESP32-S3. Chromium: 12 сочетаний размеров/тем, расположение и цвета, одна десятичная цифра, отсутствие демонстрационных данных, постоянная анимация и reduced-motion, нижние отступы при фиксированной навигации. Отдельный тест выполняет production HTTP polling с явными fixtures: температуры/пороги всех четырёх датчиков, охлаждение по приращению объёма, опциональный отбор, индикация реле, потеря связи. Прежние проверки BLE/OTA, Wi-Fi, калькулятора, истории, журнала, физической навигации и сохранности аппаратного ядра/RainMaker прошли.

На физическую ESP32 сборка не устанавливалась. Скриншоты тестов с fixtures не являются данными настоящего устройства. Обычные публичные API числовой точности не менялись.
