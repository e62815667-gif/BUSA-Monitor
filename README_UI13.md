# BUSA UI13 — исправления по фотографиям, 14.11.2026

Версия: `14v9-N16R8-RM-CALC4-WIFI1-UI13-20261114`. База — UI12.
Целевая плата: ESP32-S3 N16R8, Arduino ESP32 2.0.17,
16 MB Flash, OPI PSRAM, QIO, `app3M_fat9M_16MB`.

## Изменения локального приложения

- Калибровка: Вода, Куб, Колонна, Авария и сохранение находятся на одном
  экране. Поля одинаковой ширины, подписи выровнены, имена без T1–T4.
  Поправки сохраняются через прежний API, с прежним порядком индексов
  0/2/1/3 и диапазоном −10…+10 °C, шаг 0,1 °C.
- Wi-Fi: одна надпись «Wi-Fi», выбор найденной сети и пароль. Удалены
  ручной SSID, подзаголовок «Wi-Fi с интернетом» и повторный статус,
  который показывал «Не подключено» и общий совет проверить пароль.
  Сохраняются конечный поиск, повторный поиск, подключение, отключение,
  очистка пароля после успешного запроса и проверка длины UTF-8.
  Драйвер сканирования и логика подключения ESP32 не изменены.
- Рисунок: удалён движущийся яркий блик и пульсация подсветки холодильников.
  Само утверждённое изображение не заменялось. Кипение, жидкость,
  движение воды и капли сохранены. Пороги обновляют существующие узлы;
  опрос значений не вызывает повторную компоновку всей иллюстрации.
  Изменение доступной высоты после появления подписей реле отслеживается
  отдельно, чтобы нижние показания помещались и на маленьком экране.

Стили шапки, индикаторов и нижней навигации, калькулятор, GPIO,
настройки NVS, обработка датчиков, звуковые выходы, физический TFT,
RainMaker, Google и механизм OTA сохраняются. Исправления аудита UI12
остаются в силе. Длинные диагностические отчёты и другие существующие
формы сохраняют свой прежний механизм доступа; в калибровке и Wi-Fi
перелистывания на вторую страницу нет.

## Проверка

`tests/test_ui13_browser.py` проверяет встроенный производственный HTML
с HTTP-имитацией устройства на семи размерах: 320×568, 375×667,
390×636, 390×744, 390×844, 430×932 и 844×390. Проверяются границы
всех полей/кнопок, сохранение четырёх поправок в правильные параметры,
компактный режим при появлении клавиатуры, Wi-Fi, отсутствие блика,
сохранение анимаций и неподвижность разметки при повторных опросах.

Остальные проверки: стили и доступность разделов, живой HTTP-опрос,
Wi-Fi с кириллическим SSID/повторным поиском/ошибкой/восстановлением,
калькулятор, период графиков, сохранность аппаратных функций и аудит UI12.
Локальный тест аудита использует ASan/UBSan с `ASAN_OPTIONS=detect_leaks=0`:
LeakSanitizer недоступен в данном запуске под трассировкой. Собственная
проверка освобождения объектов снимков выполняется.

Снимки в проверках содержат только тестовые данные. На реальный ESP32
прошивка при сборке не записывается. Проверка на физическом iPhone и
настоящем устройстве остаётся за пользователем; локально доступен
Chromium, WebKit отсутствует. CI содержит отдельный запуск WebKit.

## Файлы и установка

- `BUSA_UI13_APP_OTA.bin`: в локальном приложении открыть
  Настройки → Обновление ПО и выбрать этот файл.
- `BUSA_UI13_USB_MERGED.bin`: запись через USB с адреса `0x0`.

Для сохранения текущих настроек предпочтительно OTA. USB merged
может перезаписать обычную NVS; полный erase не требуется.
Раздел регистрации RainMaker `fctry` не включён в USB-образ.

`ci/package_ui13.py` проверяет заголовок ESP32-S3, checksum/SHA-256,
размер приложения, разметку и точное совпадение приложения внутри USB.
Компактный USB-образ содержит bootloader, partitions, otadata и APP.
Команды CI находятся в `.github/workflows/busa-calculator.yml`.
Локально используется существующий alias `espressif:esp32:esp32s3`
на тот же официальный core 2.0.17 и явные пути к установленному GCC/esptool;
в CI используется стандартный `esp32:esp32:esp32s3`.
