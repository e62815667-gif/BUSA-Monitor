# BUSA UI12 — проверка кода, 08.11.2026

База UI11 340e477. Исправлены шесть ошибок: преждевременный перезапуск; экранирование JSON; повторное обнаружение заменённого DS18B20; чтение изменяемых String задачей Google; неполный откат удалённых настроек; потеря нового звукового импульса при истечении старого.

Подробный результат, воспроизведение и оставшиеся ограничения: [docs/AUDIT_UI12.md](docs/AUDIT_UI12.md). Оформление локального приложения, калькулятор и Wi-Fi сохранены без изменений. GPIO и назначение выходов не изменены; реле в этом проекте остаются звуковыми выходами.

Новые проверки: tests/test_ui12_audit.py. Исполняются производственные функции C++, с имитацией датчиков/NVS и параллельного обмена снимками. Исходные контракты сохраняются с явно перечисленными исключениями аудита в tests/fixtures/ui12_audited_changes.json.

ESP32-S3 N16R8, Arduino ESP32 2.0.17, OPI PSRAM, QIO, app3M_fat9M_16MB.

- BUSA_N16R8_RM_CALC4_WIFI1_UI12_APP_OTA.bin — локальная сеть.
- BUSA_N16R8_RM_CALC4_WIFI1_UI12_USB_MERGED.bin — USB, 0x0.

Пакетирование: ci/package_ui12.py. Как и в UI11, USB merged может перезаписать обычную NVS, полный erase не нужен, factory-раздел RainMaker не включён. Сборка на физическое устройство не устанавливалась.
