# БУСА-1М №001 — V14.15 N8R2 MODULE DIAG
Дата: 23.10.2026. Ветка: `lab/busa-v14-14-google-readonly-audit-20261023`.

## Назначение
Консервативная диагностическая сборка для ESP32-S3 N8R2, основанная на установленной V14.14 DUAL THEMES. Используется тот же проект, без новой ветки; ранее установленный бинарный образ ESP32 не затронут.

## Изменения к V14.14
- Идентификатор сборки: `БУСА 1М WiFi 14v15-N8R2-MODULE-DIAG`.
- Для T1–T4 значение температуры выводится как достоверное лишь при наличии независимой диагностики 1-Wire: presence, ROM найден, CRC корректен, семейство DS18B20, нет нескольких ROM на линии.
- В `temperatures[]` добавлено поле `verified`; при отсутствии подтверждения `c=null`.
- В `diagnostics.onewire[]` добавлено поле `measurement_verified`. Этот признак не подтверждает реальную точность измерения или исправность физической проводки; это консервативный программный фильтр.
- Сохранены существующие проверка I2C 8/9 (PCF8575 0x20, PCA9685 0x40), клавиатура 5×4, TFT ST7789, счётчик YF-S401 GPIO15, собственный Wi-Fi AP/STA и телеметрия Google.
- GPIO температуры: 16,17,18,21. Сохраняются отображение независимых тем TFT/iPhone, статистика сетевых ошибок, диагностика OTA-разделов.
- Поскольку аппаратные проверки исполнительных нагрузок не проводились, управление физическими выходами не активировано; доступен только виртуальный контроль.
- Удалённая установка BIN с Google через Интернет **не реализована** в V14.15; Google продолжает передавать только телеметрию и информацию каталога. Базовая V14.14 также не имеет облачного OTA-установщика.

## Пределы достоверности
- Из ранее полученной реальной телеметрии T2 сообщал `MULTIPLE_ROM`, а T3 — `NO_PRESENCE`. Это требует проверки аппаратных соединений отдельно от прошивки; новая логика не должна подменять эти ошибки видимостью нормального измерения.
- Отсутствие `verified=true` **не** является измерением реальной температуры. Не использовать диагностические показания для опасных автоматических действий.
- Ожидаемые образы, после успешной компиляции: APP OTA (только локальная подтверждённая установка) и USB MERGED (резервное восстановление с ноутбука).
- Наличие собранного образа и хэша SHA-256 не доказывает успешную установку и работу на настоящем контроллере.
